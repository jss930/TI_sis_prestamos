# ADR-013: Revisión administrativa de cuentas

**Estado:** aceptado.

## Decisión

Una cuenta nueva queda `PROVISIONAL`. El registro exige código institucional único. Una cuenta autorizada revisa datos, puede solicitar correcciones y valida guardando actor y fecha.

La persona solo modifica sus datos mientras la cuenta está pendiente. No se permite autovalidación.

## Consecuencias

- Una cuenta provisional consulta catálogo, pero no reserva.
- La revisión queda identificada.
- La validación no concede permisos operativos.
- Código y observaciones solo son visibles para personas autorizadas.
